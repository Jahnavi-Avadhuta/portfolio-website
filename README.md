# 🚀 Getting Started

## Prerequisites
- Node.js  
- npm  
- Git  

## 1. Clone the Repository
```bash
git clone https://github.com/Jahnavi-Avadhuta/portfolio-website.git
cd portfolio-website
```

## 2. Install Dependencies
```bash
npm install
```

## 3. Start Development Server
```bash
npm run dev
```

## 4. Build for Production
```bash
npm run build
```

## 5. Preview Production Build
```bash
npm run preview
```
